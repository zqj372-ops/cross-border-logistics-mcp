# MCP Admin 控制台

[文档中心](../../docs/README.md) / MCP 控制面

管理 MCP 接入、模块状态、审批和审计摘要。**整柜业务操作在 [Portal 运营端](../console/README.md)**；本目录不维护业务价格、税率或客户订单。

## 本地预览

在仓库根目录执行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/apps/admin/?fixture=1`。只有显式 `fixture=1` 才启用演示数据；页面标注未连接正式后台，草稿不持久化。申请人与审批人为两个演示身份，凭证不进入页面、URL 或浏览器存储。

不带该参数时请求同源 `GET /admin/api/v1/snapshot`。失败或字段不完整显示不可用，不退回演示数据。静态预览服务器没有此 API，因此非 fixture 页面不可用是预期结果。

## 模块操作顺序

```mermaid
flowchart LR
  A[登记制品] --> B[校验 / 预览]
  B --> C[双人审批]
  C --> D[发布]
  D --> E[服务端读回]
  E --> F[需要时预览回滚]
```

页面开关只改期望草稿。发布、读回和回滚以服务端状态为准；不进行乐观成功提示。`manual_review`、`blocked`、`unavailable` 保留原状态。此流程不代表支持任意代码远程安装或无重启热插拔。

## 展示边界

| 可以展示 | 不能据此推断 |
| --- | --- |
| 已校验的平台快照、权限与审批阶段 | 页面可见就有生产发布资格 |
| 来源状态及受影响工具 | 一个来源失败等于整个平台失败 |
| 配置、凭证和版本是否存在 | 凭证可用或业务来源已获正式核验 |
| 已知工具与来源的关系 | 未注册的旧 quote / PDF 工具已经启用 |

具体引用、凭证、地址、报价明细和税务正文不回显。缺字段显示未返回，不生成默认权限。旧 Phase 1 工具状态只适用于该合同，不用于否认当前 Portal 的原生报价能力。

## 运行安全

构建复制四个固定静态资源，但不会自动开启界面。`MCP_ADMIN_UI_ENABLED` 默认关闭；未设置时路由 blocked/404，非法值 unavailable/503。

当前 Runtime 的静态 `/admin` 在 Bearer 鉴权之前，只允许本机回环访问。**不得直接暴露公网**。多人管理需要批准的身份网关、管理角色、租户绑定和来源校验。只读快照不能代替真实发布 API，也不能作为业务来源探测器。

## 检查

```bash
node --check apps/admin/app.js
node --check apps/admin/fixture-data.js
node apps/admin/self-check.mjs
```

检查覆盖中文展示、敏感引用隐藏、缺字段处理、工具到来源关系和模块控制面失败闭合。分别打开 fixture 和非 fixture 地址，确认不会自动切回演示数据。

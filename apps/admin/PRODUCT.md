# FreightClaw 物流能力工作台

<!-- product-spec-version: 2026-09-05.reuse-workbench.v1 -->

> 本文描述已经实现的入口版界面。用户最新要求改为 API 直连，并增加用户管理与申请审批，当前目标见 [API 平台产品规划](../../docs/product/2026-09-05-mcp-product-redesign/11-api-native-platform-prd.md)。下面的外链行为是待替换现状，不是新版验收标准；本轮仅完成产品规划，未修改此页运行代码。

## Platform

Web（桌面与移动端响应式企业工作台）。

## Users

- 企业业务人员：从同一工作台进入正式报价、关税查询与税费估算服务，并查看运行能力。
- 运营与管理员：管理租户、发布、权限、审计、故障和 MCP 调用入口。
- 集成维护者：核对业务入口配置、Runtime 证据和独立服务状态，但不在浏览器内填写或传递密钥。

## Product Purpose

用一个浅色、紧凑的企业工作台组织物流业务入口与 MCP 管理任务。业务服务保留各自权威、登录和权限边界；Admin 负责提供可发现、可解释的安全入口，以及真实的运行与治理证据。

## Operating Context

- Admin 当前共 11 页：工作台、询价工作台、关务查询、税费估算 4 个业务入口，以及能力与配置、Agent 接入、审批与发布、审计日志、数据连接、工具权限、系统结构 7 个管理页。
- 首页首屏是业务启动区：加拿大尾程正式询价为主入口，关税查询与税费估算组成右侧辅助入口；下方再呈现服务状态和管理摘要。
- 当前部署由服务器启动配置提供报价服务 `https://quote.freightclaw.net` 和关务服务 `https://clearddp.com`。这两个地址不是前端硬编码默认值；未配置时界面显示配置说明与重试入口。
- 浏览器独立读取 `GET /admin/api/v1/business-entrypoints` 获取业务入口。该读取不依赖 Runtime snapshot 是否就绪，避免管理快照故障遮蔽已经配置的业务入口。

## Capabilities and Constraints

- 首页、正式询价、关税查询、税费估算都复用既有服务页面，不在 Admin 内复制报价、税率、措施或历史记录的权威实现。
- 外部服务以新标签页打开，使用 `noopener noreferrer`，不通过 URL、表单或脚本传递当前页面资料。
- 原服务的登录、租户和业务权限保持独立；入口“已设置”只说明配置存在，访问状态仍需在原服务验证。
- 正式询价页提供加拿大尾程主入口，并保留运维和业务辅助入口；关务页提供商品归类/关税查询入口；税费估算页进入原关务计算器。
- MCP 自动业务调用、统一登录、跨服务 handoff、资料自动带入和历史恢复尚未实现。本工作台不扩大既有 T0 权限，也不把外部页面打开视为调用成功或业务完成。
- 管理页只展示服务端返回的目录、状态和证据，不假定固定工具数量，不生成假完成状态。

## Brand Commitments

- 视觉保持可信、克制、专业，适合高频物流运营和权限治理。
- 蓝色用于主要动作与当前任务，浅蓝用于安全的业务辅助面板；状态颜色只表达可验证状态。
- 文案明确区分“入口已设置”“访问未验证”“服务不可用”和“业务已完成”，不以装饰性成功提示替代证据。

## Product Principles

1. **业务优先**：四个常用业务入口在桌面和手机上都优先可达。
2. **权威留在原服务**：报价、税率、措施、计算和业务历史由既有服务负责。
3. **状态分层**：入口配置、Runtime 状态、原服务登录和业务结果分别判断。
4. **无隐式交接**：当前跨页动作只打开服务，不自动传递客户资料或恢复历史。
5. **管理可追溯**：租户、发布、审计、故障、客户端与 API 信息保持明确任务边界。

## Navigation Behavior

- 桌面端使用 224px 左侧栏，展示 4 个业务入口和 7 个管理页；移动菜单按钮隐藏。
- `900px` 及以下固定展示 4 个常用业务入口，菜单按钮展开 7 个管理页；管理菜单不依赖横向滚动。
- 选择页面后移动菜单自动关闭；按 `Escape` 关闭菜单并将焦点归还菜单按钮。
- `640px` 及以下业务启动区改为单列，按钮保持可触达尺寸和清晰焦点。

# FreightClaw · 能力市场与操作手册

## 设计依据

用户指定 [Wind Alice Market](https://aifinmarket.wind.com.cn/#/home) 为主要参考。本轮采用其轻顶栏、首页接入提示、可检索市场、详情配置区和左侧目录手册的组织方式，重新编排 FreightClaw 已实现的能力。没有复制第三方品牌、文案、用户数据或未实现的产品。

## 视觉规则

| 元素 | 当前实现 |
| --- | --- |
| 主画布 | 浅色 `#f8f9fc`，阅读区域白色 |
| 主色 | `#3659db`，用于主操作、选中分类和章节 |
| 主导航 | 68 px 顶栏，首页 / 市场 / CLI / 操作手册 / 个人中心 |
| 首页 | 左对齐业务标题、海运与关税双入口、日常工具及 CLI/API 接入 |
| 市场 | 协议筛选、搜索、左侧业务分类，桌面三列、平板两列、手机一列 |
| 详情 | 左侧业务介绍与实际输入输出，右侧接入提示和操作 |
| 手册 | 左侧七章目录，右侧正文；手机目录局部横向滚动 |
| 个人中心 | 当前企业与页签，Key 表格、服务申请、业务工作台 |
| 图标与字体 | 内联 SVG，系统中文字体；不依赖外部图片或字体服务 |

页面靠间距、字重和简洁边界形成层级。参数、原始结果和部署细节按任务需要出现；不将权限实现术语作为普通用户必须完成的步骤。

## 行为与响应式

公共首页、市场、详情和手册无需登录。需要业务权限的操作进入正式邮箱登录。个人中心按角色显示可完成的任务，普通业务成员不进入申请或 Key 创建表单。

桌面、平板和手机保持相同信息结构。菜单支持 Escape 关闭和焦点恢复，菜单展开时主要内容 inert；表格和章节可以局部滚动，页面不可横向溢出。按钮、输入、错误文本和加载状态必须真实响应。

一次性 Key 截图前必须清空或遮挡；所有业务状态来自后端，不合成成功。用户确认保存 Key 后，在同页显示只读验证结果，避免再次要求复制和输入。

## 统一入口调整

官网根路径与控制台共用同一首页组件和构建资产。主服务区采用现有深蓝、蓝色与浅色底，海运询价与关税查询并列；实际运输环节标记起运、到港、清关与派送。CLI 采用同一套导航、浅色说明正文与深蓝终端示例，保留公众可读和窄业务权限。

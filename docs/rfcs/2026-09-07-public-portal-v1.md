# 公开服务入口与访客关税额度

状态：accepted，2026-09-07。接受依据：用户明确要求公开页面、将个人中心收进账号图标，并随后限定“尾程查询不需要开放，关税这里设置未登录每天20次查询”。根代理维护本 RFC、产品说明、Portal 集成及测试；不修改 MCP 工具和长期 Key 合同。

## 范围与合同

首页、市场、CLI、操作手册、关税查询、税费估算公开。尾程查询、个人及企业历史、Key、成员、申请、授权和写操作继续使用现有登录与角色检查。平台身份也从公开首页进入，通过账号菜单进入管理工作区。

新增窄路由 `/console/api/v1/public/customs/quota`（GET）、`/public/customs/query`、`/public/customs/tax-estimate`、`/public/customs/tax-estimates/batch`（POST）。POST 相对路径均在 `/console/api/v1` 下，输入仍为严格 `{ "input": <现有来源输入> }`；需要匿名会话的 CSRF 和同源校验，不需要人员登录。禁止任何报价、历史、写操作或任意路径代理。原人员接口与机器接口完全保留认证约束。

旧行为：匿名打开 `#customs` 跳转登录。新行为：直接填表查询，来源结果保持原有包络与五态。响应头附带访客额度；额度耗尽返回 HTTP 429、`blocked`、`public_daily_limit_reached`。查询参数、调用方提交的身份与跨租户字段一律拒绝。

## 发布身份与额度

来源连接配置显式指定发布应用、企业、租户、客户端与公开的两个关务操作，缺省关闭。每次调用检查发布应用、企业、负责人及网关租户、客户端仍有效；服务端使用该连接已配置的 service actor，禁止伪造用户或借用访客身份。来源缺数据仍返回 `unavailable` / `manual_review`。

访客按可信客户端网络地址每日共享 20 次：IPv4 地址、IPv6 /64；北京时间零点重置，关税与税费共用，批量按商品数计次。输入校验后、调用来源前原子扣减；已发出的查询尝试计次，结果不确定时不退回额度。清 Cookie、并发请求或重启不重置。仅保存每日 HMAC 网络摘要、次数和重置窗口，不保存原始地址、商品或税务材料。现阶段 SQLite 配额库用于单实例部署；多实例模式不得静默使用独立本地额度库。

## 迁移、验证和回滚

增加独立、持久化的访客配额库，不改现有业务表。备份现有 Portal 发布、配置及状态后，部署新构建并显式启用关务发布配置。校验 20/21 次边界、午夜重置、并发与重启、IPv6 等价地址、批量计次、CSRF/Origin、身份注入、所有私有路由及发布应用停用。浏览器覆盖匿名导航、账号菜单、登录后角色和手机布局。

验证命令：`npm test`、`npm run typecheck`、`npm run lint`、`npm run validate:schemas`、`npm run validate:agent-standards`、`npm run build:agent-pack`、`npm run build`、`git diff --check`。具体结果与截图记入交付说明。

回滚：恢复上一 Portal 镜像、静态入口及配置；新配额库保留。关闭配置即可禁用公开来源调用；原人员与 API Key 合同不受影响。

生产边界沿用已隔离的 Cloudflare 隧道 → 本机 HTTPS → Portal 代理。HTTPS 端口仅绑定回环；由代理传入的单一客户端地址在 Portal 的可信代理名单下读取。迁移时不得将该端口公开并继续盲信访客自填的转发头。

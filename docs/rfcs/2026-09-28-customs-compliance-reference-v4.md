# 商品进口参考依据 v4

状态：已接受；延续本任务对关税、进口限制、反倾销、反补贴及紧凑表格的授权，用户于 2026-09-28 回复“确认授权，并补齐”。只补官方参考证据，不发布正式归类或税费规则。

## 原因与合同

参考结果已有税目、税率和译名，但双反、认证与单证只能显示空的待核验。复用 `customs.query`、现有只读参考服务和表格；不新增业务实体、写接口或依赖。

原响应：`{"schema_version":"portal-customs-reference@2026-09-28.v3","status":"manual_review","data":{"formal_ready":false,"candidates":[],"search":{"terms":["商品名"],"assisted":true}},"reason_codes":["customs_reference_only"]}`（省略已有来源字段）。

新响应：版本为 `portal-customs-reference@2026-09-28.v4`，保留全部原字段，可在 `data.search` 增加 `hs6_hints`（最多 3 个通过官方资料存在性检查的六位字符串），可增加 `data.compliance:{snapshot_sha256,collected_at,date_mismatch,truncated,catalogues,remedies,guidance}`。未配置为 null。所有对象闭合；完整 Draft 2020-12 Schema 由同一 Zod 合同生成。Web/API/CLI 同时支持 v1–v4；正式响应、调用权限、额度和查询输入不变。

## 证据与边界

`customsReference.compliance:{snapshotFile,sha256}` 显式绑定离线采集 JSON。启动时检查绝对路径、普通文件、25 MB 上限、哈希、来源 HTTPS 主机、对象形状、重复身份、计数及抓取时间。数据只在重启时装载，不创建权威税费数据库。

加拿大从 CBSA 当前在施清单筛选 China（不包含 Chinese Taipei），逐项保留范围、排除和原文。美国从官方公开目录已验证的 China 案件清单取回每案详情，记录为 active_proceeding；目录含调查，不能一律当作已生效税令。缺少范围或税号仍记录为覆盖缺口。不同国家编码不混用。双向编码前缀只产生可能关联，不能据此确认适用或无措施。

响应最多返回 60 个关联案件，每案显示最多 2,000 字符的范围摘录、截断标记、案件号、抓取时间、原文哈希和官方链接；完整原文保留在采集文件。范围裁决及反规避结果随原文保存。已撤销记录单独统计 excluded_rescinded；监管指南的来源文本快照可为实际取得的 HTML 或公开页面文本，原件元数据记录获取方式，哈希不冒充其他格式。摘录不是完整排除清单，UI 必须提示打开官方完整范围。目录计数、缺详情数量、截断以及查询日期不等于采集日期都可见。未命中不等于免征。

监管指南按宽泛章号提示核验入口，全部条件适用，既不是正式规则命中，也不是完整清关单证清单。通用要求适用于任意候选，食品／动植物、无线、消费品、纺织、医疗等提示附主管机构及原文。来源文本校验、哈希和抓取时间进入证据；不可把成功抓取等同于法律适用性审核。中国页仍只是税号资料；不提供中国出口准入结论。

跨品类实测证明，仅依赖字面检索词会把杯子误搜到纺织零件、狗粮误搜到其他饲料。因此 v4 取代 v3“模型绝不提供编码”的检索限制：在同一次、同样仅发送商品名称的已授权请求中，允许最多 3 个六位 HS 候选检索方向，不允许国家扩展税号。只有所选国家当日官方资料存在此前缀才接受；原始名称直接命中官方品名时忽略模型编码方向，但保留翻译词供目的国细分排序；否则有效方向限定候选范围，不再混入宽泛关键词匹配。仅在已限定的 HS6 内用原词或首个翻译词的局部匹配排序，不能扩展检索；无品名匹配时优先宽泛税目，避免把任意特定用途当作首选。排除条款的品名提及不作为正向命中。机器方向经真实资料存在性验证也不等于语义归类确认，UI 必须标示“机器建议，待复核”。模型不能生成税率、许可证、双反结论或监管要求。中文锚点内部优先目的国原文匹配，避免宽泛 HS6 把不同商品排在前面。所有结果仍为 `manual_review`、`formal_ready:false`，额外税及完整应缴税费继续待核验。

## 工作台业务入口


## 正式业务页面与目录的关系

| 页面 | 面向用户的目标 | 当前真实行为 | 对应后端候选 |
| --- | --- | --- | --- |
| 关税查询 | 从商品资料确认加拿大编码、税率、措施和来源 | 本地检查 `query`、`rule_date`、材料、用途和钢铝属性；正式按钮禁用 | `customs.ca.search`；`customs.ca.estimate` 当前不可用 |
| 正式询价 / 加拿大尾程 | 准备加拿大尾程报价并查看只读费用 | 本地检查仓库、邮编、地址类型、货物和日期；正式按钮禁用 | Quote v2 adapter 与合同，未接入生产 runtime |
| 正式询价 / Freightcom | 准备托盘零担资料并查看只读费用 | 本地检查提送地址、日期、逐托明细和附加服务；正式按钮禁用 | 现有仅测试预览；正式版需独立合同与 adapter |

业务页面可以展示快照中的相关工具和数据连接，但快照只帮助定位缺项。它不能让禁用按钮变为可用，也不能把测试、fixture 或未发布能力升级成正式结果。

## 详情页动作

| Tab | 主要内容 | 主动作及限制 |
| --- | --- | --- |
| 用途与示例 | 输入、输出、用途和限制 | [分配给 Agent](03-agent-onboarding.md)，带入能力但仍需确认实际权限 |
| 配置 | 已生效参数、允许编辑的字段、作用范围 | 检查配置并[提交变更](04-changes.md)；无配置定义时只读 |
| 授权与接入 | 已分配 Agent、交付状态、各自验证时间 | 进入指定 Agent 详情调整，避免误改所有 Agent |
| 运行情况 | 该能力最近调用状态与上游情况 | [查看异常原因](05-operations.md)；无证据时不显示健康结论 |

## 关税查询详情的特殊规则

页面固定显示“正式调用未开通”。编码候选不是正式归类，现有 adapter 的成功结果也没有足够字段支撑正式税率页。正式版至少需要：编码与确认状态、税率分项、适用监管措施、适用日期或有效期、发布/数据版本和逐项来源引用。任一税率或措施缺来源时保持 `manual_review` 或 `unavailable`，不能由 AI、知识文档或旧结果补齐。

税额估算与税率查询分开。`customs.ca.estimate` 当前固定 `unavailable` 且零 HTTP；正式税额还需要完税价格、币种、贸易待遇等独立合同，不能用税率展示页假装已经完成估算。

## 正式询价详情的特殊规则

正式询价保留加拿大尾程和 Freightcom 两条互斥表单，因为输入合同不同。尚未确认正式供应商路径；按已有代码成熟度可建议先验收加拿大尾程，但产品不能把建议写成选择结果。

两条路径的正式结果都必须保留来源币种、费用分项、有效期、适用限制、来源引用和发布版本。首期结果继续 `sendable=false`、不可结算、不可订舱；页面不提供“发送客户”或“下单”。基础资料检查只说明浏览器中的必填项符合准备规则，不代表上游接受、获得费率或生产调用成功。

Freightcom 测试响应继续显示“测试 / 人工复核 / 不可发送或订舱”。现有 USD 数字重标只能放在次级说明并标记“未换汇”；正式 Freightcom 必须建立新的生产合同和 adapter，不能只替换测试 host。

## 待接入能力详情

说明“计划解决什么”“已有哪部分”“还缺什么”“下一责任人是谁”。主动作是查看缺项或补充需求，不显示“安装”“立即启用”“一键上线”。浏览器会话如何获得业务调用权限、如何防跨租户、如何记录脱敏审计，都必须由新 RFC 决定；现有 `t0-v1` 不因页面新增而扩权。

## 筛选与层级

首屏只保留名称、用途、类型、当前最相关原因和主动作。风险等级、工具代码、版本、来源等放详情；高级用户可通过搜索工具名定位。状态字段必须兼顾无权限、未读取、过期与失败，不能全部转成“未配置”。

## 首次使用与日常使用

首次无 Agent 时，只给一句用途说明、一个“接入一个 Agent”主按钮和“先浏览能力”次入口，不显示空白大屏指标。

日常使用按责任显示待办：待我审批、我发起但需处理、我管理的 Agent 待交付/待验证。申请人与审批人看到不同主动作。无待办显示“当前没有需要你处理的事项”，不推导“全部服务正常”。

这是目标只读视图，当前没有已核实的统一待办接口。实现可先把接入、配置和审批按来源分区呈现；缺少的关联数据不能由页面猜测。产品角色也需与实际后端权限映射核对。

## 失败与空态

- 某一来源读取失败：该区域显示“暂时无法读取，最后确认于……”，其余区域保留。
- 没有读取权限：说明当前角色允许的范围，不展示越权对象数量。
- 会话到期：进入重新登录，保留允许的非敏感页面位置；不让用户再次把 JWT 粘进业务表单。
- 无真实调用数据：隐藏指标或显示暂无记录，不填充演示数值。

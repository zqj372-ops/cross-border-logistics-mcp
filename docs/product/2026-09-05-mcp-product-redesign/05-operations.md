# 页面 05：运行记录与异常处理

[方案总览](README.md) · [工作台](01-workbench.md) · [能力目录](02-capabilities.md) · [Agent 接入](03-agent-onboarding.md) · [变更中心](04-changes.md) · **运行记录**

> 低保真设计示例，无真实客户信息、调用记录、费用或凭证。状态必须以实际来源读取，不能由示例填充正式页面。

## 记录列表

```text
运行记录
[调用记录] [管理操作]

组织 [当前组织 ▾]    Agent [全部有权限 Agent ▾]
能力 [全部 ▾]        结果 [需要处理 ▾]          时间 [选择范围]

时间        Agent / 对象       能力 / 动作          结果             操作
──────────────────────────────────────────────────────────────────────
示例时间    示例仓储助手       装柜容量摘要         缺少必要输入     [查看]
示例时间    示例客服助手       凭证更换             待交付           [继续]
示例时间    测试配置           参数修改             未确认生效       [查看]
```

调用和管理操作通过 Tab 区分。它们可以共享搜索和详情布局，但各自状态含义保持不变。无记录时写“当前筛选下暂无记录”，不会推断没有异常；来源读取失败时必须单独显示。

## 问题详情

```text
装柜摘要未完成
缺少运营目标及来源，无法判断是否符合运营装载要求。

影响对象
组织：示例组织 A    Agent：示例仓储助手    能力：装柜容量摘要

下一步
由业务操作人补充已确认的运营目标及来源，然后重新测算。
[查看需要补充的信息]       [返回记录]

处理依据
结果：需要补充信息
最近检查：实际时间
来源：实际调用结果
[展开技术详情：原因码 / 请求引用 / 工具与规则版本]
```

对业务输入不足，后台只定位缺项和责任人；不自动保存原始客户输入。若从该页面跳转到受支持业务入口，仅传允许的引用，不把原始地址、税务材料或 Key 放入链接。

## 不同问题的恢复去向

| 问题 | 用户首先看到 | 去向 |
| --- | --- | --- |
| 权限未分配 | 这个 Agent 还没有该能力的权限 | [Agent 详情](03-agent-onboarding.md) |
| 凭证未交付或过期 | 接入凭证尚未可用 | 目标凭证的交付/更换流程 |
| 控制台检查通过但目标客户端无证据 | 客户端仍待验证 | 目标客户端连接指引 |
| 能力配置待审批 | 配置尚未应用 | [对应变更](04-changes.md) |
| 变更结果未知 | 尚未确认生效 | 同一操作的核验或协调流程，不盲目重提 |
| 上游暂不可用 | 外部服务暂时无法使用 | [能力运行情况](02-capabilities.md)及实际责任人 |
| 正式合同未齐全 | 这项能力暂未开放 | 能力接入缺项，不给无效重试按钮 |
| 需要人工判断 | 哪些结果需要核对、可接受什么证据 | 查看引用；只有任务 API 可用且有权限时才创建任务 |

## 管理操作详情

给出“谁、何时、针对哪个对象、申请了什么、服务端返回什么、结果是否核验”。展示新增/移除的能力及脱敏凭证元数据，不显示完整 Key；完整技术事件可折叠，失败历史不抹掉。

## 首页待办与这里的关系

首页待办是这类事实的简短投影，不另建一套可手工改为成功的状态。处理后重新读取来源；相同问题可以归组展示，但仍保留每项原始操作引用。

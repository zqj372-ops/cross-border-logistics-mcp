## 已完成的修复

| 问题 | 当前行为 | 验证 |
| --- | --- | --- |
| 数据包接收与实际查询的发布检查不一致 | 来源、独立审核引用数量、绑定哈希和未解决事项使用相同检查 | 14 组查询/接收门禁一致性案例，以及错误哈希、缺审批案例 |
| 管理文件启用后发生变化仍可能被读取 | 首次读取重新计算 SHA-256；缓存期间检测文件变化并停止查询 | 首次读取和缓存后的变更回归，不回落旧 JSON |
| 没有特定税号提示的通用措施被丢弃 | 通用措施进入原有规则评估，保留法律范围及人工复核状态 | 内存和 SQL 查询均覆盖 |

| 八位税目不能匹配十位统计税号 | 仅显式 prefix 规则扩展；同来源且条件完全相同的重复税率去重 | 前缀、相邻税号、过期、重复和冲突案例 |
| 找到税号但缺少税率时可能给出成功包络 | 保留归类状态；缺可用合计或措施/单证待复核时返回 manual_review 和明确原因 | 单一国家、已确认税号、无税率的隔离回归 |
| 加拿大候选准备不可复现、忽略源格式变化 | 移植维护 CLI，固定版本及哈希，保留元数据/重复行证据并检查品名、表头和来源差异 | 合成导出测试、来源 Schema 兼容性与真实 ZIP 重建 |

加拿大税号的前八位为税目，后两位为统计后缀；税率匹配修复依据 [CBSA 税号结构说明](https://www.cbsa-asfc.gc.ca/trade-commerce/tariff-tarif/guide/read-lire-eng.html) 与 [D10-13-1](https://www.cbsa-asfc.gc.ca/publications/dm-md/d10/d10-13-1-eng.html)。新候选中，5,148 个有品名的可申报统计税号没有重复填写完整税率，可通过显式八位税目规则找到 MFN。这个计数是数据关联覆盖检查，不表示这些商品的归类、附加税与全部进口条件已经确认。

## 官方章节交叉检查的范围与结果

已重新取得 01、02、03、24、27、28、29、71、73、81、88、91、97 共 13 章的双语 HTML，逐文件验证 URL、哈希、语言、T2026-2、发布日期与表头。检查范围仅为这 13 章，不能宣称所有章节已完成。

- 英文核对 2,221 个税号/待复核空名记录，其中 **2,121 条简单 MFN 税率一致**。
- 两种语言分别发现 43 条 CADEx 记录未在相应 HTML 章节找到；8 条空名记录有对应章节文本。不能以“页面没找到”为由直接删除法规记录或宣布旧码已废止。
- 英文有 52 条复杂税率文本差异，1 条空白 MFN 有章节值；这是核对项，不直接转成数值或覆盖来源。
- 每种语言有 4 组官方 HTML 同码重复记录，包含单位差异；程序保留两条证据要求复核。

这些计数按检查类型统计，部分涉及同一条记录，不可相加当作不同税号数。开始发现的 6 条英文统计税号空白 MFN，进一步核对后可关联到八位税目，未凭法文值增造六条独立税率。剩余真实差异需要使用对应法定文件及版本变更记录核对。

候选输出包括 `release.json`、`quality-report.json`、`normalization-report.json` 和 `source-audit.json`，保留原 ZIP、ACCDB、CSV 和章节文件；都位于本地私有运行目录，未提交法规数据到 Git。使用步骤见 [CBSA 离线 CLI](../runbooks/cbsa-candidate-preparation.md)。

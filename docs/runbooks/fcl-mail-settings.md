# 邮件设置

运营后台 → 报价与邮件设置。

1. 展开「更换发信服务」，填写服务器、账号、密码、发件邮箱和发件人名称。
2. 保存连接草稿。当前发信服务继续使用。
3. 发送测试邮件，核对收件箱和发件人名称后，点击「启用新服务」。
4. 展开需要调整的业务节点，填写内部收件邮箱并启用提醒，保存邮件设置。

节点默认设置用于新业务；在途订单在本票内调整。客户通知与内部通知分开。邮箱不授予后台权限。

发信配置仅固定受理人可管理。密码不回显。发送结果不明时先核对收件箱，不反复重试。

财务提醒：在「客户确认下单」设置内部收件邮箱。只在客户确认已发布报价后触发；报价审核、发布及运营接单不重复触发。不补发历史订单。

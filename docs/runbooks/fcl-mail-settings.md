# 邮件设置

[文档中心](../README.md) / [运营手册](../guides/operations.md) / 邮件

入口：**运营后台 → 报价与邮件设置**。发信连接由固定受理人管理。

![客户、内部和对接人通知的区别](../assets/mail-audiences.svg)

## 更换发件邮箱

1. 展开「更换发信服务」，填写 SMTP 服务器、端口、安全方式、账号、密码、发件邮箱和发件人名称。
2. **保存连接草稿**。此时仍使用原服务发信。
3. **发送测试邮件**，在收件箱核对发件名、正文和回复地址。
4. 测试确认后点击 **启用新服务**，刷新页面确认已启用。

SMTP 用于发送。IMAP 收件服务器不代替 SMTP，也不代表系统已经支持自动读取来信。密码不回显，不写入文档、截图或日志。

## 给各节点设置收件人

展开需要调整的节点，填写内部收件邮箱、抄送和负责人，勾选「启用内部提醒」，保存邮件设置。执行节点可另设对接人邮箱与允许发送的资料。

| 设置 | 用途 |
| --- | --- |
| 内部收件人 | 接收运营协作提醒 |
| 负责人账号 | 决定系统内的工作归属；须为已核验的个人账号 |
| 对接人邮箱 | 接收该节点允许对外发送的资料 |
| 客户可见进度 | 给本票客户查看和接收通知，内部记录不会发送给客户 |

**邮箱不授予后台权限。** 全局设置用于新业务；在途订单在本票内调整。保存设置本身不发送业务邮件。

## 财务提醒

在「客户确认下单」设置财务内部收件邮箱，并启用提醒。

只在客户确认已发布报价后触发。报价审核、发布和运营接单不会重复触发；开启后不补发历史订单。它是收单提醒，不代表开票、收款或付款已完成。

## 正文与附件

预览时核对主题、SO / 柜号或询价号、正文、收件人、抄送和允许可见的字段。对接人邮件不包含成本、利润和内部备注。

报关阶段从本票选择已上传附件，核对后发送。发送记录与订单关联；上传文件成功不等于已发邮件。

## 如何判断成功

| 状态 | 含义 / 处理 |
| --- | --- |
| 已保存 | 配置或业务记录已保存，不代表邮件已发出 |
| 邮件服务器已接收 | 服务器接受发送，仍需收件人核对收件箱 |
| 已收到、内容正常 | 收件人确认的送达证据 |
| 发送失败 | 检查配置和错误，再决定是否重试 |
| 结果不明 | 先查记录与收件箱，不反复发送 |
